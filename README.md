# Legacy iOS & Jailbreak Hardware Bench

A Dev-Team / `libimobiledevice` Terminal User Interface (TUI) for inspecting, wirelessly pairing, and checking jailbreak & TSS signing status on iOS devices on Linux.

## Quick Start (Linux Mint / Ubuntu / Debian)
1. Install system dependencies:
   ```bash
   sudo apt update && sudo apt install git libimobiledevice-utils ideviceinstaller usbmuxd usbutils python3-venv -y
   ```
2. Run the automated setup:
   ```bash
   bash run.sh
   ```
